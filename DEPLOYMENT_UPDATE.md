## Troubleshooting

### Issue: "Failed to fetch" in chat
**Fix:**
1. Check Vercel has `BACKEND_URL` set correctly
2. Verify Render backend is running (check logs)
3. Test backend health endpoint directly

### Issue: CORS errors in browser console
**Fix:**
1. Verify `FRONTEND_URL` in Render matches your Vercel URL exactly
2. Make sure both use `https://` (not `http://`)
3. Redeploy Render backend after changing

### Issue: "Lite Mode" still showing
**Fix:**
1. Check Render backend has `GEMINI_API_KEY` set
2. View Render logs to see if AI initialized
3. Verify frontend `BACKEND_URL` points to Render (not localhost)

### Issue: Database connection errors
**Fix:**
1. Copy `DATABASE_URL` from Render database
2. Paste same URL in both:
   - Render backend environment
   - Vercel frontend environment
3. Must include `?sslmode=require`
